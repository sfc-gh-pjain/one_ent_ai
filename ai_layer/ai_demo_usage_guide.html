Live Demo Tips

Good Prompt Patterns

  • "What is [metric] by [dimension]?" — always works
  • "Which [entities] have the highest/lowest [metric]?"
  • "Show me [metric] for [filter condition]"
  • "Compare [metric] across [dimension values]"
Vague: "Tell me about the data" (no specific metric)
Too complex: "Rx volume for HCPs engaged in oncology drugs in the Northeast" (too many joins)
Missing context: "Show me the trend" (no time dimension available)

Recovery Phrases

  • "Let me rephrase — what I mean is [simpler version]"
  • "Let me try a more specific question..."
  • If wrong domain: "I meant this for the [Healthcare/CRM/Finance] domain"

Pre-Demo Checklist

  • Verify Streamlit apps load (bust cache: ALTER STREAMLIT ... SET COMMENT)
  • Test one prompt per tab before audience arrives
  • Have Enterprise Agent Preview tab open in a separate Snowsight tab
  • Keep SHOW SEMANTIC VIEWS IN DATABASE DEMO ready for governance angle
  • Confirm search service is ACTIVE: SHOW CORTEX SEARCH SERVICES IN SCHEMA DEMO.HEALTHCARE_DEMO
  • Have backup SQL worksheet open

Backup SQL Queries

If AI features are slow during live demo, run these directly:

-- Top drugs by Rx volume SELECT d.DRUG_NAME, d.THERAPEUTIC_AREA, SUM(m.METRIC_VALUE) AS total_volume FROM DEMO.HEALTHCARE_DEMO.RX_METRICS_OUTPUT m JOIN DEMO.HEALTHCARE_DEMO.DIM_DRUG d ON m.DRUG_ID = d.DRUG_ID WHERE m.METRIC_NAME = 'total_rx_volume' GROUP BY d.DRUG_NAME, d.THERAPEUTIC_AREA ORDER BY total_volume DESC; -- At-risk accounts with exposure SELECT ACCOUNT_NAME, INDUSTRY, REGION, HEALTH_SCORE, TOTAL_PIPELINE + WON_REVENUE AS REVENUE_EXPOSURE FROM DEMO.CRM_DEMO.CUSTOMER_360 WHERE SEGMENT = 'At Risk' ORDER BY REVENUE_EXPOSURE DESC; -- Budget variance by product line SELECT PRODUCT_LINE, REGION, SUM(ACTUAL_REVENUE) - SUM(BUDGET_REVENUE) AS variance FROM DEMO.HEALTHCARE_DEMO.FINANCE_REVENUE_SUMMARY GROUP BY PRODUCT_LINE, REGION ORDER BY variance DESC; -- HCP tier distribution SELECT TIER, COUNT(*) AS hcp_count FROM DEMO.HEALTHCARE_DEMO.HCP_TIERED_PROFILES GROUP BY TIER ORDER BY hcp_count DESC;
