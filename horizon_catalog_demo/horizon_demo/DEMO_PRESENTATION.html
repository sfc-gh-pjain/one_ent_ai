Data Governance Policies

Five policy types provide defense-in-depth protection

PolicyApplied ToWhat It DoesRole Behavior
MaskingSSN, Email, Phone, AddressTag-based dynamic maskingSYSADMIN=clear, Clinical=last4, Analyst=fully masked
Row AccessPATIENTS.DEPARTMENTFilters rows by departmentClinical sees only CARDIOLOGY
AggregationBILLING tableMin group size = 5Prevents re-identification
JoinPATIENTS tableMust JOIN (no standalone SELECT)Analysts cannot bulk-export
ProjectionPRESCRIPTIONS.MEDICATION_NAMEBlocks column projectionAnalysts cannot see Rx names

One masking policy reads PII_LEVEL tag via SYSTEM$GET_TAG_ON_CURRENT_COLUMN() — scales to all PII columns automatically. Uses IS_ROLE_IN_SESSION() for correct role hierarchy traversal.
